Der zuletzt verwendete Tresor ist gerade nicht erreichbar (z. B. NAS ausgeschaltet oder Laufwerk nicht verbunden). Lege nur dann einen neuen an, wenn du das wirklich willst.

Was möchtest du tun?

Verbindungsart
Der Ordner muss ein Netzwerkpfad sein (\\server\freigabe\…). Das Passwort wird verschlüsselt für deinen Windows-Benutzer gespeichert, damit PassMind die Freigabe beim nächsten Start selbst verbindet.

Die Netzwerk-Anmeldung gibt es nur unter Windows. Verbinde die Freigabe hier im Betriebssystem (macOS: Finder → Gehe zu → Mit Server verbinden, Linux: Dateimanager) und wähle dann Standard.

Neuer Tresor:

Der Superuser ist Admin des Tresors und meldet sich immer lokal an, auch wenn später die AD-Anmeldung dazukommt.
Optional: Schlüsseldatei als zweiter Schlüssel

Ohne die Schlüsseldatei lässt sich der Tresor dann nicht mehr öffnen. Bewahre sie getrennt vom Tresor auf (z. B. auf einem zweiten USB-Stick) und mach eine Sicherungskopie.

Neue Schlüsseldatei herunterladen

Scanne den QR-Code mit einer Authenticator-App (z. B. Microsoft Authenticator, Google Authenticator, Aegis, 2FAS).

Oder Schlüssel manuell eingeben:

Wiederherstellungscodes: Damit kommst du an den Tresor, wenn das Handy mit der Authenticator-App verloren geht. Jeder Code funktioniert einmal. Drucke sie aus oder speichere sie sicher, getrennt vom Tresor.

    Wie soll PassMind aussehen? Du kannst später jederzeit oben mit ☀/🌙 umschalten. PassMind merkt sich die Einstellung auf diesem Rechner.

    Lege weitere lokale Benutzer an. Jeder bekommt ein Startpasswort und richtet beim ersten Anmelden sein eigenes Passwort und seine Authenticator-App (MFA) ein. Für den gemischten Betrieb mit Active Directory schalte darunter die AD-Anmeldung ein. Beides geht auch später in den Einstellungen.

          Zum Beispiel auf ein NAS oder Netzlaufwerk verschieben, um den Tresor von mehreren Rechnern zu nutzen. Änderungen anderer Rechner werden automatisch zusammengeführt. Die bisherige Datei bleibt als Kopie liegen.

              Persönlichen Tresor entsperren

              Dein persönlicher Tresor ist mit deinem AD-Passwort verschlüsselt. Seit dem letzten Mal wurde das Passwort geändert. Gib einmal dein bisheriges AD-Passwort ein, danach öffnet er sich wieder mit dem neuen.
