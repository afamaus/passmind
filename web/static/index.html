Hier lag früher ein Tresor, er ist aber gerade nicht erreichbar (z. B. NAS ausgeschaltet oder Laufwerk nicht verbunden). Lege nur dann einen neuen an, wenn du das wirklich willst.

Der Tresor wird hier gespeichert:

Anderen Speicherort oder vorhandenen Tresor wählen

Du wirst Admin und kannst später weitere Benutzer anlegen. Jeder bekommt ein eigenes Passwort und eine eigene Authenticator-App.
Optional: Schlüsseldatei als zweiter Schlüssel

Ohne die Schlüsseldatei lässt sich der Tresor dann nicht mehr öffnen. Bewahre sie getrennt vom Tresor auf (z. B. auf einem zweiten USB-Stick) und mach eine Sicherungskopie.

Neue Schlüsseldatei herunterladen

Scanne den QR-Code mit einer Authenticator-App (z. B. Microsoft Authenticator, Google Authenticator, Aegis, 2FAS).
